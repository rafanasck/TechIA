TechIA - Assistente de Tecnologia

Sobre o projeto

O TechIA é uma aplicação desktop desenvolvida em Python que simula um chatbot para responder perguntas sobre programação e tecnologia. O sistema possui tela de login, conversa com o assistente e opções para personalizar a interface.

Funcionalidades

Login com usuário e senha.

Chat com perguntas e respostas sobre tecnologia.

Histórico de mensagens durante a conversa.

Botão para limpar a conversa.

Alternância entre modo claro e modo escuro.

Respostas com pequeno atraso para simular o funcionamento de um chatbot.

Tecnologias utilizadas

Python

Tkinter

Biblioteca random

Requisitos

Python 3 instalado.

Editor de código, como Visual Studio Code.

O Tkinter geralmente já vem instalado com o Python.

Como executar o projeto

Baixe ou clone este repositório.

Abra a pasta do projeto no Visual Studio Code.

Abra o terminal.

Execute o comando:

python main.py

Caso o comando não funcione, tente:

py main.py

Funcionamento

O sistema utiliza respostas previamente programadas para perguntas sobre assuntos como Python, Java, HTML, CSS, JavaScript, PHP, SQL, APIs e algoritmos. As respostas são simuladas localmente, sem conexão com uma API externa de inteligência artificial.
